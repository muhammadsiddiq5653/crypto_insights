Risks & Mitigations
Eyes open on every risk.
Mitigations already in motion.
Risk
API dependency (Binance, CoinGecko)
Free tier rate limits could throttle live data
Mitigation
6-exchange fallback chain + TTL cache + synthetic data with clear labels. Upgrade to paid APIs at scale ($200/mo).
Risk
Regulatory exposure
Misclassified as unregistered broker
Mitigation
Positioned as research & analytics tool. No order routing, no custody, no financial advice. Clear legal disclaimers.
Risk
Crypto bear market churn
Users drop tools in downturns
Mitigation
Free tier keeps users engaged. Education (Academy) + DCA content optimised for accumulation mindset. Macro/FRED data is bear-market relevant.
Risk
Scaling SQLite beyond 10k users
Single-process SQLite is not horizontally scalable
Mitigation
Migration path defined: Redis sessions → PostgreSQL (app.db) → TimescaleDB (market.db). Architecture already modular for this swap.
