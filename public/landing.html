Common questions

Everything you need to know before you start.

The free Starter plan gives you the coin cockpit for 3 coins with daily signals, exchange comparison and the latest news. Pro ($20/mo) unlocks everything: all 10 coins, multi-timeframe signals, the 3-Agent AI Council, Signal Command Center, Strategy Backtester, Trade Journal, Portfolio Tracker with Binance sync, Smart Alerts with Slack webhooks, Performance Dashboard, FRED macro feed, live WebSocket ticker and server-side SQLite persistence.
Three specialist agents run in parallel for every analysis: the Technical Analyst scores RSI, MACD and ADX rule-based signals; the Sentiment Analyst reads the SignalBus and Fear & Greed index; the Risk Manager checks volatility and computes Kelly sizing. A Chief Analyst then takes a weighted vote across all three and produces the final BUY/SELL/HOLD verdict with a Quarter-Kelly position size recommendation.
Yes. TraderPro runs a server-side alert cron every 60 seconds that checks all your active alerts against live Binance prices — completely independent of your browser. When a condition triggers, the server POSTs directly to your Slack webhook so you get notified even if the tab is closed or you're away from your desk.
Choose one of 4 strategies (RSI Mean Reversion, MA Crossover, MACD Signal Cross, Bollinger Squeeze Breakout), pick a coin and timeframe, and the backtester fetches real Binance kline history. It simulates every entry and exit with your chosen stop-loss and take-profit percentages, then shows win rate, total R, max drawdown and a canvas equity curve against a buy-and-hold baseline.
Enter your Binance read-only API key and secret in Settings. The server signs the account balance request with HMAC-SHA256 on your behalf — your secret never leaves the server and is never exposed to the browser. Stablecoins are skipped automatically and imported holdings are merged with any manually entered positions.
No. Every core feature — prices, signals, Fear & Greed, Polymarket odds, exchange comparison, backtester, trade journal — works with zero API keys. Optional keys unlock extra power: OpenRouter for the AI Council, FRED for macro data, Slack for alert notifications, and Binance read-only for portfolio sync.
For each timeframe (1H, 4H, 1D), TraderPro fetches the last 50–60 candles from Binance, computes RSI(14), SMA20/50, MACD(12,26,9) and volume ratio, then scores each indicator. A weighted consensus (1D has 3× weight, 4H 2×, 1H 1×) determines the overall direction. All computation is client-side — no third-party signal service. Signals are also emitted to the SignalBus for the Command Center to pick up.
Yes. TraderPro is self-hosted — your journal trades, portfolio holdings, alerts and API keys are stored in a SQLite database on your own machine. Nothing is sent to any third-party analytics service. Binance API secrets are stored server-side only and masked in all UI displays.
Copy .env.example to .env, generate a strong SESSION_SECRET, set NODE_ENV=production. Then run pm2 start ecosystem.config.js --env production. PM2 runs in cluster mode with automatic restart and log rotation. The server-side alert cron starts automatically on boot. For HTTPS, put nginx in front as a reverse proxy.
